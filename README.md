## Public restaurant reviews as an early warning indicator for foodborne outbreaks: an exploration in NYC
This repository contains R and Python scripts for scraping public restaurant reviews, database design, and predictive models.

### Repository structure
All included code can be run in R or Python, with the required packages indicated at the top of each script. All scripts are in the **Code** folder. Data available for download are listed below. 

### Data sources
The following data sources may be used in the analysis and are publicly available for download:
- Yelp
- Google
- Twitter
- TikTok
